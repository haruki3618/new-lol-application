# スマホ・タブレットの 3 分チェック

実機で開いて、**見づらい・押しにくい所を書き出す**ためのシートです。直すのは後で構いません。まず「どこが困るか」を集めます。

## 準備
- 実機を 2 つ以上（できれば小さい画面の iPhone / Android と、タブレット）
- 回線は Wi-Fi と モバイル回線の両方（表示の速さが違う）
- 確認するプレイヤーは、試合が 30 件以上あるアカウントを 1 つ決めておく
- 日付・端末・OS・ブラウザを書いておく（下の表の最上行）

## チェック（上から順に、各 20〜30 秒）

| # | 画面 | 見ること | OK | メモ（崩れ方・端末） |
|---|---|---|---|---|
| 1 | トップ `/` | 検索欄が画面内に収まる。キーボードが出ても送信ボタンが隠れない | ☐ | |
| 2 | トップ | リージョン選択が押しやすい | ☐ | |
| 3 | プロフィール `/summoner` | 画面の横幅からはみ出す表が無い（横スクロールが出ない） | ☐ | |
| 4 | プロフィール | タブ（概要・チャンピオン・分析・LP…）が横にスクロールでき、隠れた側がぼけて見える | ☐ | |
| 5 | プロフィール | 試合カードをタップして開閉できる。アイコンが小さすぎない | ☐ | |
| 6 | プロフィール | 「もっと見る」「同期」のボタンが指で押せる大きさ（目安 44px 以上） | ☐ | |
| 7 | LP タブ | グラフが画面幅に収まり、タップで数値が出る | ☐ | |
| 8 | チャンピオン一覧・詳細 | 表が読める。絞り込み欄が使える | ☐ | |
| 9 | ランキング | 表がはみ出さない。ページ送りが押しやすい | ☐ | |
| 10 | ライブ `/live` | 10 人分が読める。経過時間が進む | ☐ | |
| 11 | 横向き（回転） | 崩れない | ☐ | |
| 12 | 文字の拡大（OS の設定で大きく） | 文字が切れない・重ならない | ☐ | |
| 13 | ライト／ダーク（ナビの ◐） | どちらでも文字が読める | ☐ | |
| 14 | 機内モードにして操作 | 「接続されていません」が出て、戻したら復帰する | ☐ | |
| 15 | 回線を弱くして（モバイル・低速）プロフィールを開く | スケルトン／進捗が出て、固まって見えない | ☐ | |

## 結果の使い方
- ☐ のままの行が **直す候補**。メモの内容を `UX_SCENARIOS.md` の「変更案」か、CHANGELOG の次の版の項目に書き写す
- 直したあとは同じ行をもう一度確認する
- 端末が違うと出方が変わるので、直らなかった端末名も残す
