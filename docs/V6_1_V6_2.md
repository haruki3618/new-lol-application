# v6.1（ライブゲーム強化）と v6.2（タイムライン分析）

このフォルダは v6.0 に v6.1・v6.2 を適用済みの **完成形** です。新しい依存パッケージ・DB 形式の変更はありません（`.env` もそのまま使えます）。

```
npm install && npm test && npm run start:all
```

## v6.1 ライブゲーム強化（`/live`）
各プレイヤーに次を表示します。
| 項目 | 元データ | API |
|---|---|---|
| そのチャンピオンでの試合数・勝率・95%の幅・KDA | 保存済みの試合 | なし |
| 直近10試合の勝敗・KDA | 保存済みの試合 | なし |
| 全体の勝率（同じキューが10試合以上あればそのキュー、無ければ全キュー） | 保存済みの試合 | なし |
| マスタリー（Lv・ポイント） | champion-mastery-v4 by-champion | 10人で10回（10分キャッシュ） |
| ランク | league-v4 | 従来どおり（2分キャッシュ） |

### 簡易の勝敗予想
- 見るのは **個人成績だけ**（そのチャンピオンでの勝率と全体の勝率）。チャンピオン相性・ドラフト・連携・ランク差は見ません。
- 少ない試合数の勝率は全体の勝率へ引き寄せます（縮小推定。仮想の試合数: 全体20・チャンピオン10）。2戦2勝でも 100% とは扱いません。
- **試合数が10未満の人は「データ不足」** で、予想の計算では平均的として扱い、推測で強い・弱いとは決めません。十分なデータのある人が **6人未満なら予想を出しません**。
- 結果は 30〜70% に制限し、差が3ポイント未満は「ほぼ互角」、8未満は「やや優勢」。
- 基準値は `src/services/liveMath.js` の `LIVE_DEFAULTS`。

### データ不足の人の取得
「データ不足の N 人の直近の試合を取得」ボタンを押したときだけ、1人あたり最大 11 回（試合ID 1 回 + 試合 10 回）の API を使い、保存してから再読み込みします。取得済みの試合は API を使いません。5分以内の再取得は行いません。

## v6.2 タイムライン分析
プロフィールの試合を開き、**「タイムライン分析を読み込む」** を押した試合だけ分析します（1試合につき match-v5 timeline 1回）。
- 10・15・20分時点の CS・ゴールド・経験値、レーン相手（同じロールの相手チームのプレイヤーが1人に決まる場合のみ）との差、チームのゴールド差。
- チーム・レーン相手とのゴールド差の推移グラフ（SVG）。
- 自分のキル・デス・アシスト数とデスの時刻、10分までのデスが2回以上なら記載。
- ドラゴン・グラブ・ヘラルド・バロン・タワー・インヒビターを、自チーム／相手で色分け。
- 「所見」は事実の言い換えのみ: CS差8以上、15分のゴールド差（レーン800・チーム1,500以上）、最大差3,000以上での逆転勝ち／先行からの敗北、序盤デス。
- 保存: 軽くしたタイムライン（毎分の [ゴールド, CS, 経験値, レベル] とキル・モンスター・建物イベント）を `CacheEntry` に30日。再表示や別の人の視点での表示は API を使いません。

### 制限
- Riot のタイムラインは古い試合では取得できません（その旨を表示）。
- CS にはジャングルのモンスターを含みます。ジャングル・サポートの CS・ゴールド比較は参考程度です。
- ロールが不明な試合・同ロールが重複する試合ではレーン相手の比較は出しません。
- 時刻ごとの値は毎分のスナップショットです（細かい瞬間の差は見えません）。
